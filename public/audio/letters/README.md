# Harplaryň ses ýazgylary (islege görä)

Bu papka goýlan `.mp3` faýllar brauzeriň TTS sesiniň ýerine ulanylýar.

| Faýl ady         | Näme okalýar                    |
|------------------|---------------------------------|
| `ba.mp3`         | Harpyň ady (بَاء)               |
| `ba-a.mp3`       | Üstün bilen: بَ                 |
| `ba-i.mp3`       | Astyn bilen: بِ                 |
| `ba-u.mp3`       | Ötre bilen: بُ                  |

Harplaryň `id`-leri: `src/data/letters.ts` faýlynda.
